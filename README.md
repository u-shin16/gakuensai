# モンスター診断カード（学園祭 2026-11-21 の試作）

8つの質問に答えると16タイプのどれかに決まり、好きなものと絵柄を選ぶと、
AI（Gemini）がその人の分身になるモンスターを描いてカードにする。

## 動かし方

```
./venv/bin/python app.py
```

http://localhost:8120 を開く。同じWi-Fiのスマホからは `http://<このPCのIP>:8120`。

- `.env` に `GEMINI_API_KEY` が無いときは「お試しモード」（ダミーの絵と文章）で動く
- 試してもらった結果は http://localhost:8120/api/stats で見られる（お試しモードの分は数えない）
- 記録は `data/log.jsonl`（タイプ・好きなもの・レア度・答えた値段・日時のみ。名前は取らない）
